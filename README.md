## What is Wan 2.7 Image?

Wan 2.7 Image (通义万相 2.7) is the latest AI image generation model from Alibaba's Tongyi Wanxiang team, released April 2026. It supports:

- **Text to Image** — Describe any scene and generate high-quality images
- **Image to Image** — Edit existing photos with natural language prompts
- **4K Output** — Ultra-high-resolution generation with Wan 2.7 Image Pro
- **Thinking Mode** — AI reasons about your prompt for more accurate results
- **Text Rendering** — Accurately renders text in images (posters, logos, etc.)

## Tech Stack

This project is built on [ShipAny](https://shipany.ai) SaaS template:

- **Framework:** Next.js 16 (App Router + Turbopack)
- **UI:** React 19 + Radix UI + Tailwind CSS 4
- **Database:** Turso (libSQL) + Drizzle ORM
- **Auth:** Better-Auth (Email + Google OAuth)
- **AI:** Vercel AI SDK + Replicate + Fal.ai + Gemini
- **Payment:** Stripe / PayPal / Creem
- **Deploy:** Vercel
